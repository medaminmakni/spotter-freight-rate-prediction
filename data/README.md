# Data

The dataset belongs to Spotter and is not included in this repository.
Copy these files from the assessment package into this folder:

- `train_test.csv` — 48,000 labelled loads (Jan–Oct 2025)
- `validation.csv` — 12,000 loads to predict (Nov–Dec 2025)
- `validation_predictions_template.csv`
- `december_chart_inputs.csv`
